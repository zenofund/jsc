## How To Use This Guide

- Capture real screenshots from the live application.
- Use one clean screenshot per slide where possible.
- Highlight only the most important areas with simple callouts.
- Avoid crowded screens with too many arrows or notes.
- Use short labels such as `Menu`, `Create`, `Approve`, `Save`, `Status`, and `Report`.
- Where a process has multiple steps, use 2 to 4 screenshots instead of forcing everything into one image.

## Screenshot Rules

- Use full-screen desktop screenshots unless the detail is too small.
- Hide browser clutter if possible.
- Use realistic sample data, not empty pages.
- Blur or avoid sensitive personal data if needed.
- Keep zoom level readable for projector display.
- Show the left menu and page title whenever possible.
- Use the same browser size for consistency across all screenshots.

## Recommended Slide Structure

For each screenshot slide, use this simple layout:

- **Slide title:** Name of the module or task
- **Screenshot:** Main screen image
- **Callouts:** 3 to 5 simple labels
- **Trainer note:** One sentence explaining why the screen matters

Example:

- **Slide title:** Create Payroll Batch
- **Callouts:** `Select Month`, `Generate Lines`, `Review Totals`, `Submit`
- **Trainer note:** This is the starting point for monthly payroll processing.

## Recommended Callout Style

Keep callouts very short:

- `Click Here`
- `Start Here`
- `Review`
- `Approve`
- `Reject`
- `Save`
- `Export`
- `Status`
- `Filter`
- `Next Step`

Avoid long explanations inside the screenshot itself. Put longer explanation in trainer notes or speaker notes.

## Recommended Color Meaning For Callouts

- **Blue:** navigation or where to click
- **Green:** success, approval, or final action
- **Orange:** review or caution
- **Red:** rejection, warning, or restricted area

## Simple Trainer Tips

- Do not explain every tiny field on a slide.
- Explain only what the learner must notice first.
- Move from simple screens to complex screens.
- Always connect the screen to a business action.
- Remind learners which role should use each screen.
- End each section by showing what happens next in the process.
